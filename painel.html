Entrar no painel

Use a sua chave de acesso do GitHub. Só quem tem uma chave com permissão neste repositório consegue editar o site.

Como conseguir a chave (uma vez só)
  1. Entre no GitHub e abra github.com/settings/personal-access-tokens/new.
  2. Token name: "Painel ADDAI". Expiration: escolha uma data (ex.: 1 ano).
  3. Repository access: "Only select repositories" → escolha site-addai.
  4. Permissions → Repository permissions → Contents: "Read and write".
  5. Clique em Generate token, copie a chave e cole aqui. Guarde-a num lugar seguro: o GitHub só mostra uma vez.

Para dar acesso a outra pessoa, adicione-a como colaboradora do repositório (Settings → Collaborators) e ela gera a própria chave. Nunca compartilhe a sua.

Como funciona: edite, clique em Ver prévia para conferir e depois em Publicar no site. Em cerca de 1 minuto o site atualiza para todos.
Você tem um rascunho não publicado neste navegador. Ele só aparece na prévia — os visitantes continuam vendo o conteúdo publicado até você clicar em Publicar no site.

Seções do site

Desligue o que a ADDAI ainda não usa. Informativos, Números de impacto e Parceiros também ficam escondidos enquanto estiverem vazios. Boas-vindas, Como ajudar e Contato ficam sempre visíveis.

Textos da página inicial

Imagens do carrossel

Fotos escolhidas do computador são reduzidas automaticamente e ficam embutidas no conteudo.json. Use sempre fotos com autorização de quem aparece nelas.

Informativos

Aparecem no site do mais recente para o mais antigo (pela data). A página inicial mostra os 4 primeiros; os demais ficam em "Ver todos os informativos".

Quem somos

Missão, visão ou valores em branco não aparecem no site. Para esconder a seção inteira, use "Seções do site".

Sem foto, o texto ocupa a largura da seção. Use fotos com autorização de quem aparece nelas.

Seções personalizadas

Crie seções novas na página inicial (ex.: "Nossa história", "Eventos", "Transparência"). Escolha onde ela entra e, se quiser, coloque no menu — use o menu com moderação, para ele caber numa linha.

Números de impacto

Ex.: valor "+120", texto "famílias acolhidas". Valor vazio aparece como marcador amarelo.

Parceiros

Sem parceiros cadastrados, a seção não aparece no site. Prefira logos em PNG com fundo transparente.

Dados da associação

Campo vazio = o site mostra o marcador amarelo de "a preencher".

Cópia de segurança

Baixa o conteúdo atual do painel (textos, fotos, informativos) num arquivo conteudo.json.

Publicar no site?

As alterações ficam visíveis para todos os visitantes em cerca de 1 minuto.

Descartar rascunho?

As alterações não publicadas deste navegador serão apagadas e o painel volta a mostrar o conteúdo publicado.
